This file includes the advanced information other developers and enthusiasts may need to work with this project.

## Language files
- You can add custom language files and it'll automatically add to the GUI once you restart the program.
(This is because I preload all of the languages into the GUI on startup.) <br>
- If you are missing keys then it'll default to en_us.json. <br>
- If you edit the file, deselect and re-select it, then the updated version will be loaded. <br>

## Folders
- All UI and GUI is located in folder `axaml`. <br>
- UI helpers and other classes are put in folder `classes`. <br>
- Json and other data is put in folder `data`. <br>
- Language must be in folder `lang`. <br>
